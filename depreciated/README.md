# Depreciated Code

This folder contains older mission implementations and experimental code that is no longer actively used.

## Contents

- **run_demo_*.py**: Tutorial demonstrations for learning PyBricks (motors, sensors, multitasking)
- **run_*_version_*.py**: Historical mission implementations with version iterations
- **run_missions_*.py**: Mission sets from previous team members
- **nothing.py, ting.py**: Test/placeholder files

## Usage

These files are kept for reference and historical purposes. For active mission development, use the main `run*.py` files in the repository root or create new missions there.

To reference or adapt code from these files:
1. Review the tutorial demos (`run_demo_*.py`) for PyBricks examples
2. Extract useful patterns for your mission implementation
3. Create new mission files in the root directory

## Notes

- Some code may reference older configuration or hardware setups
- Not maintained or tested with current robot configuration
- Safe to delete if not needed for historical reference
